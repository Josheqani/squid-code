# Sound Assets

Place your optional `.mp3` sound effect files in this folder matching the keys in `src/hooks/useGameAudio.js`:

- `squid-game-theme.mp3` - Iconic Squid Game background soundtrack / Dalgona theme
- `footsteps.mp3` - Heavy soldier boot steps as the guard enters
- `dome-lift.mp3` - Metallic scrape & ring as the silver cloche lifts
- `candy-crack.mp3` - Crisp sugar fracture / needle chip sound
- `candy-scratch.mp3` - Tactile needle carving friction sound
- `candy-shatter.mp3` - Heavy candy fragmentation failure sound
- `buzzer.mp3` - Ominous Squid Game elimination buzzer
- `celebration.mp3` - Triumphant chime / piggy bank fanfare
- `button-click.mp3` - Tactical UI button click

> **Note:** The application includes a Web Audio API procedural sound synthesizer and music sequencer. Even if no physical `.mp3` files are added, authentic procedural audio synthesizes the exact Squid Game soundtrack melody ("Way Back Then" recorder motif + rhythmic woodblock ticking), crisp candy cracks, cloche lifts, and elimination buzzes in real-time.
